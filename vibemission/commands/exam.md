description: VibeMission 코딩 시험 시작/제출 (start <토큰> | submit | status)
argument-hint: "[start <토큰> | submit | status]"
---

너는 VibeMission 코딩 시험 진행을 돕는다. 사용자가 입력한 인자: **$ARGUMENTS** (없으면 status)

Bash로 다음을 **그대로** 실행하고($ARGUMENTS 를 인자로 전달), 출력을 사용자에게 **그대로** 보여줘라:

```
node "${CLAUDE_PLUGIN_ROOT}/bin/exam.mjs" $ARGUMENTS
```

- `start <토큰>` → 시작 시 토큰을 함께 받는다(처음 한 번만 입력하면 `~/.vibemission/config.json` 에 저장돼 이후 명령은 토큰 없이 동작한다 — 셸 `export` 불필요). 출력 맨 위의 `📝 과제: …` 줄(과제명)을 **글자 그대로** 먼저 보여주고(요약·번역·변형 절대 금지 — 툴 출력의 제목을 그대로), 이어서 brief(문제 내용)를 그대로 보여주고 "평소처럼 저에게 지시해서 풀어보세요. 모든 과정이 기록됩니다."라고 안내한다. **정답을 미리 풀어주지 말고, 사용자의 지시에 따라서만 작업한다.** 평가는 사용자가 AI를 어떻게 부리는지(프롬프트·검증·반복)를 본다.
- **작업 규칙**: **새 빈 폴더**에서 작업하라 — 사용자의 기존 프로젝트 파일·설정(`launch.json`, `.claude/`, `CLAUDE.md`, `package.json` 등)을 건드리거나 덮어쓰지 말 것. 결과물은 **가능하면 단일 자체완결 HTML 한 개**로 만들면 결과 화면에서 바로 실행돼 보기 좋다(권장). 더 큰 프로젝트(React 등 여러 파일)도 괜찮다 — 모든 과정·파일이 기록되어 채점되며, 단일 HTML이 아니면 결과 화면은 라이브 실행 대신 코드·파일로 보여준다. 평소처럼 실행·테스트로 검증해도 좋다(단, 그 새 폴더 안에서만).
- `submit` → 출력에 나온 **결과 카드 링크(resultUrl)**를 클릭 가능하게 보여주고 "이 링크를 누르면 점수·등급·전세계 랭킹 카드가 열립니다"라고 안내한다. 제출 후엔 더 수정하지 말라고 한다.
- `status` → 남은 시간/상태를 보여준다. 시간이 다 되면 자동 종료되며 결과 링크가 나온다.

토큰이 없다는 안내가 나오면, 셸 export가 아니라 **Claude Code 채팅창에 `/vibemission:exam start <받은 토큰>`** 을 입력하라고 안내한다. 토큰은 받은 메일/화면의 명령 안에 들어 있다(cleanmissionai.kr 에서 발급).
